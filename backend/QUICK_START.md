# Quick Start - Backend Setup

## Проблема "Failed to fetch"

Эта ошибка означает, что фронтенд не может подключиться к backend API. Вот как её исправить:

## Решение 1: Запустить Backend (рекомендуется)

### Шаг 1: Установите зависимости
\`\`\`bash
cd backend
pip install -r requirements.txt
\`\`\`

### Шаг 2: Настройте переменные окружения
\`\`\`bash
cp .env.example .env
\`\`\`

Отредактируйте `.env` и добавьте ваш DATABASE_URL от Neon.

### Шаг 3: Инициализируйте базу данных
\`\`\`bash
python init_db.py
\`\`\`

Это создаст все таблицы и тестового пользователя:
- Email: `admin@test.com`
- Password: `admin123`

### Шаг 4: Запустите сервер
\`\`\`bash
python main.py
\`\`\`

Backend будет доступен на `http://localhost:8000`

### Шаг 5: Проверьте подключение
Откройте в браузере: `http://localhost:8000/docs`

Вы должны увидеть интерактивную документацию API.

## Решение 2: Режим разработки без Backend

Если вы не хотите запускать backend, вы можете использовать демо-режим:

1. Используйте учетные данные: `admin@test.com` / `admin123`
2. Фронтенд покажет демо-данные

## Проверка статуса Backend

Выполните в терминале:
\`\`\`bash
curl http://localhost:8000/health
\`\`\`

Должен вернуть: `{"status":"healthy"}`

## Типичные проблемы

### Порт 8000 уже занят
\`\`\`bash
# Найдите процесс
lsof -i :8000
# Убейте процесс
kill -9 <PID>
\`\`\`

### CORS ошибки
Убедитесь, что в `backend/main.py` добавлен ваш фронтенд URL в `allow_origins`.

### База данных не подключается
Проверьте `DATABASE_URL` в `.env` файле.
